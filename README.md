# Conqueror of Elements

A 2D platformer and logic puzzle game built in C++ using the **SFML** library, heavily inspired by the classic **Fireboy and Watergirl** series. The project features custom physics-based player movement, advanced collision detection, interactive object states, and multi-level progression across four elemental themes (Water, Fire, Earth, and Wind).

## Features
- **Inspired by Classics**: Classic puzzle-platformer mechanics inspired by *Fireboy and Watergirl*, focusing on environmental interaction and level-solving.
- **Player Mechanics**: Comprehensive `Player` class handling custom movement speed, gravity, jumping velocity, directional sprites, and state persistence.
- **Advanced Collision System**: Robust boundary checks for screen edges and environmental objects, supporting movable boxes, pressure plates, and levers.
- **Interactive Puzzles & Environment**: Trigger mechanisms that alter textures or clear obstacles, collectible elemental diamonds for score tracking, and cave portals leading to level progression.
- **Game State Management**: Smooth flow supporting a main menu, interactive tutorial, gameplay across 4 distinct elemental levels, and an end-game screen.
- **Audio & UI**: Background music loop and on-screen control buttons for restarts and quick help access.

## Technologies Used
- **Language**: C++
- **Library**: SFML for window management, 2D graphics rendering, and audio.
